# A.I BOX 1.3.1 — Deep Hat

- Adicionado **Deep Hat**, modelo de cibersegurança da Kindo, à categoria Código.
- A entrada direciona para o aplicativo oficial e identifica corretamente o item como modelo, não como aplicativo de IA genérico.
- O acesso gratuito é anunciado no site oficial, mas cotas e limites não estão detalhados publicamente; condições corporativas podem exigir contratação.
- O catálogo passa a conter 111 ferramentas.
- GitHub Pages publica automaticamente o catálogo atualizado pela branch main.
- O workflow Windows recompila o instalador e a versão portátil para esta versão.

O Deep Hat é destinado a atividades de segurança autorizadas. Verifique os termos do serviço antes de utilizar recursos avançados.
