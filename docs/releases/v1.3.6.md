# A.I BOX 1.3.6 — OriginKit e robustez do catálogo

## Nova ferramenta
- **OriginKit** — biblioteca de componentes de interface e animações para projetos web, com integração ao Framer e suporte a MCP para agentes de programação.
- Incluída em **Código** como Framework.
- Plano Free com catálogo e cópias limitados; planos pagos ampliam o acesso e incluem templates.
- Identificação textual enquanto não houver SVG próprio verificável.

## Correção
- Corrigida a validação do campo `kind`: erros agora identificam o ID e o valor incompatível, facilitando encontrar o registro inválido.
- Adicionado teste para garantir que valores de tipo não suportados sejam rejeitados com diagnóstico claro.
- Adicionado teste de política para confirmar a presença do OriginKit e a classificação como Framework.
