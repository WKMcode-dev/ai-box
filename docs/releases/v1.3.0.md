# A.I BOX 1.3.0 — Catálogo atualizado

- Adicionado **SSSTik** ao catálogo, na categoria Vídeo, com acesso gratuito para baixar vídeos públicos do TikTok e extrair áudio quando disponível.
- O catálogo agora contém 110 ferramentas. A compatibilidade com Shopee não foi confirmada; o SSSTik não é um modelo de inteligência artificial.
- O instalador e a edição portátil do Windows passam a incluir a versão atual do catálogo no pacote offline.
- O GitHub Pages publica o mesmo catálogo por meio do fluxo automático da branch main.

Esta versão preserva os demais recursos existentes. Para atualizar, instale o novo pacote ou use o atualizador do aplicativo quando disponível.

O instalador não possui assinatura digital comercial.
