# A.I BOX 1.3.3 — Novas ferramentas e contraste dos logos

## Novas ferramentas
- **BLACKBOX AI** — agente de programação para editor, terminal, depuração, testes e fluxos multiagente.
- **Manus** — agente de IA para tarefas em várias etapas, pesquisa e criação de entregáveis.
- **Kling AI** — geração e edição de vídeo a partir de texto e imagens.
- **OpenRouter** — interface de chat e API para acessar modelos de diversos provedores, incluindo modelos gratuitos.

## Identidade visual
- Adicionados SVGs locais de Manus, Kling AI e OpenRouter.
- BLACKBOX AI usa fallback textual enquanto o SVG oficial não pôde ser importado diretamente.
- Clareados os logos de AnythingLLM, AutoGen, PixAI, Bolt, Continue, InvokeAI, Tactiq, Deep Hat e Fish Audio para melhor contraste no tema escuro.
- Removidos fundos pretos ou cinza-escuros de marcas que já possuem símbolo claro, preservando gradientes e cores originais sempre que possível.
