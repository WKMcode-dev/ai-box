# A.I BOX 1.3.7 — Cibersegurança e ferramentas Windows/WSL

## Nova categoria
- Criada a categoria **Cibersegurança** no menu do catálogo.
- Incluídas **25 ferramentas** de análise de tráfego, auditoria web, reconhecimento, engenharia reversa, forense digital e análise de arquivos.
- As sete ferramentas inicialmente listadas foram incluídas: mitmproxy, Wireshark, Ghidra, x64dbg, FakeNet-NG, tcpdump e Burp Suite.

## Curadoria Kali Linux
- Pesquisa baseada no índice oficial de ferramentas e metapacotes do Kali Linux.
- Incluídas opções com suporte Windows nativo ou execução viável no WSL 2.
- Ferramentas dependentes de hardware Wi-Fi/SDR/RFID ou de acesso Linux não disponível no WSL foram excluídas desta rodada.
- A matriz de compatibilidade e as limitações estão em [docs/cybersecurity-tools.md](../cybersecurity-tools.md).

## Compatibilidade e segurança
- Ferramentas WSL estão identificadas no modal e não são tratadas como aplicativos Windows nativos.
- tcpdump foi marcado como WSL; Wireshark permanece a opção nativa para captura no Windows via Npcap.
- FakeNet-NG informa a limitação do modo Windows e a necessidade de laboratório isolado.
- Burp Suite está classificado como freemium por causa dos recursos pagos da edição Professional.
- Identificação textual para ferramentas sem logo oficial verificada.

## Catálogo
- Total: **143 ferramentas** em oito categorias.
