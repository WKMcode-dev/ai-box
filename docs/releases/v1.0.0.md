# A.I BOX 1.0.0 — Windows e Web

Primeira edição do A.I BOX para Windows em janela própria e GitHub Pages.

- Catálogo com 108 ferramentas e modelos, sete categorias, busca e filtros.
- Identificação de acesso gratuito e planos gratuitos com limites.
- Modal com descrição, condições e endereço oficial.
- Aplicativo Windows com catálogo integrado e links abertos no navegador padrão.
- Edição web estática, sem servidor, login ou banco de dados.

## Downloads

- `AI-BOX-1.0.0-x64-setup.exe`: instalador para Windows 64 bits.
- `AI-BOX-1.0.0-x64-portable.exe`: edição portátil, sem instalação.

Os executáveis desta primeira versão não possuem certificado comercial de assinatura digital. O Windows pode exibir uma confirmação de procedência. O catálogo vem incluído; acessar as IAs externas exige internet e pode exigir conta no serviço escolhido. A gratuidade e os limites são informados por item e podem mudar.
